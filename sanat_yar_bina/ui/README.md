# 🖥️ User Interface (GUI) Directory

## Overview
The `ui` directory contains the complete front-end architecture for the cyber-physical inspection system. Built using a modular widget-based approach (typically PyQt/PySide), this interface provides human operators with real-time visualization of the YOLOv8 inference, the Fuzzy-RL control decisions, and the automated SLM shift reports.

## Core Modules & Widgets
The GUI is heavily componentized to ensure that UI rendering does not block the real-time processing threads of the backend. 

* **Application Lifecycle & Security:**
  * `splash_screen.py` & `loading_dialog.py`: Manages the startup sequence, ensuring the heavy YOLO and quantized SLM weights are fully loaded into memory before the user accesses the system.
  * `auth.py`: Handles operator authentication and access control, ensuring only authorized personnel can alter control thresholds or view sensitive reports.

* **Main Layout:**
  * `dashboard.py`: The central orchestrator window. It instances and aligns all sub-widgets into a cohesive, dark-themed industrial control panel.

* **Real-Time Monitoring Widgets:**
  * `video_widget.py`: Renders the live video feed or simulation stream, overlaying YOLO bounding boxes, class labels, and confidence scores with zero perceived latency.
  * `log_widget.py`: Streams real-time telemetry from the SQLite WAL database and JSONL logs, displaying system events as they occur.
  * `intelligence_widget.py`: A specialized dashboard component visualizing the active state of the AI controllers (e.g., current Fuzzy severity score, RL agent's speed adjustment commands).

* **Reporting Interface:**
  * `report_widget.py` & `report_viewer.py`: Interfaces specifically designed to fetch, parse, and elegantly display the natural language summaries generated by the Edge SLM (Qwen). It allows operators to review historical shift data seamlessly.

## Threading Note
All real-time widgets (`video_widget.py`, `log_widget.py`) rely on asynchronous signal/slot mechanisms to receive data from the core engine. This ensures the GUI remains highly responsive even during intensive model inference.
